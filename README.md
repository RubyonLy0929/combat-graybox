# 战斗与装备系统灰盒 Demo

Godot 4 / 2D即时战斗 / 双武器连段 / 装备组合 / 两阶段Boss

这是一个用于验证战斗规则和装备配合的可运行原型。角色、场景、动作和界面采用灰盒占位表现，当前重点是攻击节奏、换武器衔接、装备效果和Boss机制。

## 下载与运行

**[下载 Windows 试玩包](https://github.com/RubyonLy0929/combat-graybox/releases/download/v0.8.0/CombatGraybox-v0.8-Windows.zip)** · **[下载 Godot 工程](https://github.com/RubyonLy0929/combat-graybox/releases/download/v0.8.0/CombatGraybox-v0.8-Source.zip)** · [版本说明](https://github.com/RubyonLy0929/combat-graybox/releases/tag/v0.8.0)

1. 下载后完整解压。
2. 打开 `Giant Demon Boss Graybox v0.8.exe`。
3. `.exe` 与同名 `.pck` 必须保留在同一目录。运行Windows版不需要安装Godot。

如需查看工程，下载 `CombatGraybox-v0.8-Source.zip`，解压后用Godot 4导入 `project.godot`。工程配置标记为4.7，当前Windows导出包启动时报告Godot 4.7.1；其他版本兼容性尚未逐一验证。

## 建议体验顺序

- **先看基础操作**：默认进入Boss庭院。按F1进入演武场，熟悉移动、攻击与换武器；F2返回Boss庭院。
- **再试武器和装备**：比较剑、刀、鞭、长枪、弓的攻击节奏、范围和移动限制，尝试双武器连段与装备主动。
- **最后挑战Boss**：一阶段利用掩体和预告处理固定防线，二阶段观察追击、顺劈、突进与反击窗口。45%、30%、15%生命触发固定走位机制。

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD | 移动 |
| 鼠标 / 左键 | 瞄准 / 攻击 |
| Q / 滚轮 | 切换A、B武器；符合窗口时衔接连段 |
| 1 | 当前武器主动技能 |
| 2 / 3 | 已选择的装备主动技能 |
| I / B | 背包；打开时暂停战斗 |
| E | 拾取附近物品 |
| 按住Tab | 显示地面掉落名称 |
| R | 重开当前灰盒 |
| F1 / F2 | 演武场 / Boss庭院 |

背包支持拖放、物品旋转和装备穿脱。装备主动需要在背包里选择技能来源。

开发预览：F暂停敌人与危险，G切换无敌，V切换范围显示；Boss一阶段F3预览脱困，二阶段F4/F5/F6分别预览45%/30%/15%机制。Esc可跳过机制引子，不能跳过实际躲避。

## 当前实现

### 武器与连段

五类武器各有四段攻击，分别配置前摇、判定、后摇、范围、伤害和击退。攻击期间仍可减速移动。跨武器切换包含输入缓存、段数继承和后摇取消窗口。

### 装备与资源

格子背包、装备位置与负重影响角色属性。已制作血契快攻、残像换位、法力突袭等装备组合样板；技能冷却、生命支付、有效命中收益和延迟攻击有对应结算规则。

### Boss遭遇战

一阶段为固定防线，包含剑气、炮击、扫射、一次性掩体与清场位移；二阶段加入追击、三连顺劈、蓄力突进、交叉炮线与内外逆转。固定血量机制结束后核心开放，提供反击窗口。
