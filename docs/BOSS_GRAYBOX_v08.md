# 巨型机关魔神灰盒 v0.8

2026-10-13。恢复10月8日保存的v0.7工程，在原有武器、BD、背包、拾取与两阶段Boss上更新。

## 入口与操作

Godot 4.4或更新4.x Standard版导入project.godot，F5运行默认Boss庭院。
WASD八向移动；鼠标瞄准、左键攻击；Q/滚轮双武器连段；1/2/3主动；I/B背包；E拾取；按住TAB显示掉落；R重开。
F1演武场/F2 Boss；F3脱困；二阶段F4/F5/F6直接预览45%/30%/15%机制。预览跳过更早阈值，仅供开发；在游戏窗口获得焦点时使用。Esc跳过机制引子或脱困转场，不能跳过实际躲避。
F暂停Boss与危险，G无敌，V范围显示。F不暂停玩家；背包暂停整个场景。

## 二阶段常规招式

保留三连顺劈、蓄力突进、两发点射、近身震荡；补充追猎剑气、交叉炮线、内外逆转。采用固定轮换，每招结束有恢复。

| 招式 | 处理 |
|---|---|
| 追猎剑气 | 两道慢波，锁向后避开射线 |
| 交叉炮线 | Boss所在横线与纵线同时预告，走出十字；重叠只扣一次 |
| 内外逆转 | 先离开近身圆，再进入中心避开外环；Boss保持原地 |

## 血量固定机制

血量按整条生命条百分比计算。一阶段60%脱困；二阶段依次45%、30%、15%，每个检查点整场一次。抵达阈值后先完成当前普通动作，阶段护盾显示在读条区，然后进入机制。

| 阈值 | 固定机制 | 顺序 |
|---|---|---|
| 45% | 剑阵封庭 | 三波纵向剑阵，空白通道从第二列移到第三列、第四列；地面预告按当前波出现 |
| 30% | 九连炮击 | 连续九次记录玩家位置，落点记录后不追踪，逐次移动躲避 |
| 15% | 魔神审判 | 北半场→南半场→北半场攻击，因此安全区南→北→南；随后中心圆、外环依次结算 |

每段先有约1.8秒核心升起、光带与字幕引子，期间暂停常规战斗时钟并清除遗留攻击。引子结束恢复移动，Boss核心封闭，普通攻击和伤害技能暂不出手；可切武器、使用非伤害技能如侧步和回血稳身。停手阶段的资源、冷却按真实战斗时间继续计时，没有免费重置。

机制结束清除输入缓存，需松开后重新攻击；核心开放4秒，伤害沿用既有25%暴露增益。Esc仅跳过引子。失败只承受对应机制伤害，不直接判整场失败；不依赖特定装备、QTE或成功机制才进入下一阶段。

## 阈值伤害与负重

触发阈值的那一次攻击，只立即扣到对应血量；其减伤后溢出伤害暂存。机制及反击窗口结束后结算暂存伤害，若跨下一阈值则依序触发，不重复、不丢弃溢出，也不一次跳过全部演出。阶段护盾与机制封闭期间不再接收新增伤害。暂存部分不再次触发暴击、吸血、返蓝、装备事件；即时命中奖励仅按即时实际扣血结算。该策略为本版灰盒机制编排，正式平衡时可调整。

预告按进入机制时的实际移速留出移动余量。途中换重装降低移速时，机制与其危险对象同步减慢；加速不会缩短原预告。场地位移与普通击退依旧分开；新增运动会攻击不额外施加击退，避免一次错误连续推入下一危险。

## 镜头与分辨率

统一1280×720逻辑画面、16:9等比例缩放，非16:9留边，不裁掉场地也不增加视野。Boss镜头固定在(640,360)，完整1120×480庭院可见。通知、连段提示和拾取提示移到场地下方，避免遮挡底部危险区。

探索镜头模块使用屏幕中央20%宽、15%高的自由区域，超出后平滑跟随并受地图边界限制。现有演武场本身只有一屏，保持全图可见；将来扩展地图时配置exploration_bounds并制作对应实际地图。此次没有扩建探索地图。

鼠标普通攻击只接受逻辑画面内输入；已有get_global_mouse_position继续通过引擎画面变换计算瞄准。

## 其他修复与边界

恢复Boss房间对通用自动拾取循环的调用，金币/任务物品沿用既有范围和遮挡规则；纯演出及机制弹射期间暂停拾取。

保留旧演武场、五武器、三个样板BD和所有物品。没有接入新剧情、持久存档、正式美术、元素、魂珠、绳索、连弩、商店；F1/F2与R仍是开发重置操作，不保留跨房间状态。前版v0.7工程另留备份。
