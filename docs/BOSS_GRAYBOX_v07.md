# 巨型机关魔神灰盒 v0.7

日期：2026-10-08。基于项目现存v0.6工程扩展，默认场景为scenes/boss_arena.tscn，原演武场仍为scenes/main.tscn。

## 运行

解压，使用Godot 4.4或更新的4.x Standard版导入project.godot，等待资源导入，再按F5运行项目。默认进入Boss庭院；在编辑器中单独打开main.tscn按F6可进入原演武场。

## 操作

| 操作 | 按键 |
|---|---|
| 八向移动 | WASD |
| 全向攻击 | 鼠标瞄准＋左键；J／空格也可攻击 |
| 双武器／连段衔接 | Q、鼠标滚轮 |
| 武器与装备主动 | 1、2、3 |
| 背包 | I／B，打开时暂停整个战斗 |
| 拾取 | E，金币自动拾取 |
| 显示地面物品 | 按住TAB |
| 重开当前房间 | R；背包打开时R用于旋转物品 |
| 原演武场／Boss房间 | F1／F2，切换会重置该房间的角色与物品 |
| 跳过转场 | 转场时Esc |
| 调试 | F暂停Boss及其危险，G无敌，V玩家范围；F3直接进入脱困转场 |

F3仅供开发查看，不是正式玩家能力。原演武场里用F2返回Boss房间。

## 场景与可玩内容

- 北侧巨型机器人魔神像，程序绘制坦克履带底盘、石质装甲、炮口、核心、巨剑和束缚。
- 一阶段固定在城墙中，可用近战击中碰撞体边缘，远程沿鼠标方向命中。
- 共六座一次性掩体，三组左右选择；承担保护后成为可走废墟，不刷新、不掉落资源。
- 一阶段：两道慢速剑气、三次锁定位置的高抛炮击、扇面机枪扫射、带顺序编号的三波场地炮击、防线清场。
- 防线清场：看绿色预计落点，调整横向站位；机关排斥可跨低墙，不读取普通抗击退；落地后可微调。对准高亮掩体后方可挡横扫，随后该掩体破坏。南侧撤离带始终提供基础解法。
- 60%血量达到后，完成当前攻击与恢复，清除遗留危险并进入约6秒脱困演出。阶段阈值不会重复触发。
- 转场中冻结角色资源回复、状态、冷却与连段时钟；清除箭矢／影子／Boss危险；重复挑战可Esc跳过，恢复时需重新按下攻击。
- 二阶段追击进入有效距离后停步，三连顺劈逐段锁方向，另有蓄力直线突进、慢速点射、近身震荡。
- 普通击退仍不超过受击者一个碰撞体直径；Boss免普通位移，保留战术状态和装备命中奖励。
- 核心过热期间伤害提高25%，第三刀与突进后留反击窗口；撞残留围墙破墙并延长恢复。
- 死亡可R重开；击败后掉金币、重甲和材料，仍可走动及拾取。
- 保留既有五武器、跨武器连段、装备主动／被动、红蓝条、格子背包、金币、负重与TAB掉落显示。

## 首版边界与初值

Boss生命2800、60%转场、各招伤害与时间只是灰盒初值。参数集中在scripts/boss/下；mechanism_boss.gd中的encounter_health与release_threshold可以调整。

一阶段近战为巨型碰撞体边缘攻击代理，不包含独立部位血条。三波炮击替代九连记忆版本；没有QTE、正式美术、配音和正式过场。当前转场为程序动画、字幕与碎片效果。暂未加入普通攻击击落炮弹、独立架势条、冻结累积、完整元素系统或新存档系统。

现有普通防御和资源公式继续复用；本体免位移时刀仍能获得战术失衡条件，未直接删除其BD收益。
