# v0.6 接入说明

状态：代码实现完成，语法/资源静态检查；未做Godot引擎验证与体验/平衡测试。

## 跨武器连段

段数全局共享，支持A12→B34和逐段切换。第四段后归零。跨武器0.5秒窗口从判定结束计时，不随攻速或负重缩短；换武器过渡0.1秒期间按75%当前移速移动，冷却0.35秒。普通连段保持0.5秒从后摇结束计时。

前摇/判定中只缓存一个切换请求。判定结束时执行合格请求，取消后摇；窗口外的请求等原动作结束再换，新武器从第一段开始。技能不继承普通连段，切换不能提前取消技能判定。受击打断前摇后清除继承。

五类型默认四连击保持，普通攻击仍能减速移动。新增transition动画状态使用已有待机/行走占位帧，不需要新美术。背景障碍、金币/格子背包、Tab显示掉落保持原入口。

## 技能与冷却

1固定为当前武器主动；2/3各选择一个穿戴的非武器装备主动，全部穿戴被动生效。只能选择当前实际穿戴的来源；两个栏不重复选择同一来源。选项包含无技能。

冷却以cooldown_group记录在角色运行时，装备实例不拥有独立计时。切武器、卸下、重穿不能重置；重置整个灰盒才创建新角色。技能在就绪时施放，动作期间可缓存0.7秒请求，来源变动/过期拒绝。失败不扣法力、不进入冷却。

基础法力50、自然回复1/秒；攻击消耗与恢复均同步CharacterState。被动产生的狂热通过现有buff与最终属性计算器处理，受已有攻速上限1.3与吸血上限30%约束。

## 战术状态与准备

- 枪2外侧40%命中：破绽2秒；准备后的枪4远端伤害+20%。
- 刀2实际击退至少0.15身位：失衡2秒；首领有效伤害允许替代。准备刀4增强击退驱动；跨武器刀4消耗破绽，忽略20%防御。
- 鞭2同次命中两敌：牵制2秒，减速15%；准备鞭4消耗牵制，额外0.25倍武器基准伤害。
- 弓2：猎印2秒；准备弓4消耗猎印穿两敌，第二目标60%；跨武器弓4消耗失衡伤害+20%，两收益择条件分支。
- 剑12准备：剑4暴击率+20个百分点；跨武器剑3消耗破绽可再命中第二目标，第二目标60%。

每目标最多一种战术状态。准备以武器实例与chain_id记录；需该实例的1、2段实际扣敌血。换装更换任意武器实例会清除准备、连段继承和缓存；不删除已开始攻击的剩余时间与伤害快照。挥空可以接续，但没有命中奖励。

束足减速、钉足定身是独立短控制通道；同时受到牵制时减速取最强。首领定身替换为减速。元素状态独立层仅预留，本轮没有冰冻/持续元素伤害。

## 事件与结算政策

CombatRuntime提供combat_event信号。当前事件包括attack_commit、health_cost_paid、health_damage、direct_hit、attack_hit_group、skill_cast、segment_end、switch、kill、death。

一次动作的范围或散射共用context.rewarded，只领一次固定回血/返蓝；其他攻击还受同名效果的0.5秒内部冷却限制。普通吸血按每个目标实际生命损失计算，受过量伤害截断，不按面板数值回复。

武器伤害、暴击、吸血与被动在出手时保存来源快照。已放出的箭与影子不因切武器获得新面板。目标防御在命中时结算。自伤成本先支付，生命支付不能用护甲减免，且不会造成普通受击打断。影子与附加伤害标记secondary，不走直接命中资源奖励。

死亡有death_sent保护，敌人只掉落一次。主动逐隙只有该次直接击杀才缩冷却；影子不能刷逐隙冷却。木偶和无敌目标没有实际扣血，因此无有效命中收益。霸体只免打断，不免伤或击退。
